# 🚗 Used Car Price Prediction

## 📌 Project Overview

중고차 가격은 연식, 주행거리, 사고 이력 등 다양한 요인에 의해 결정되며, 동일 차종이라도 차량 상태에 따라 가격 차이가 크게 발생한다.

본 프로젝트는 엔카(Encar) API를 직접 분석하여 차량 데이터를 수집하고, 보험이력 데이터를 추가로 확보하여 데이터셋을 구축한 후 머신러닝 모델을 활용하여 중고차 가격을 예측하는 서비스를 개발하는 것을 목표로 하였다.

단순히 공개 데이터를 활용하는 것이 아닌 API 분석부터 데이터 수집, 전처리, 모델링, 웹 서비스 구현까지 전 과정을 직접 수행한 End-to-End 머신러닝 프로젝트이다.

## 📊 Data Collection

### 엔카 API 분석

일반적인 웹 크롤링 방식이 아닌 개발자 도구(Network)를 활용하여 엔카 API 구조를 분석하였다.

수집 항목

* 제조사
* 모델명
* 연식
* 모델연도
* 주행거리
* 연료
* 변속기
* 판매가격
* 사고이력 정보

### 보험이력 데이터 수집

기본 차량 정보만으로는 차량 상태를 충분히 반영하기 어렵다고 판단하였다.

추가 API 호출을 통해 다음 정보를 확보하였다.

* 내차 피해 금액
* 타차 가해 금액
* 소유자 변경 이력
* 침수 이력
* 사고 횟수

수집한 데이터를 기존 차량 데이터와 결합하여 학습 데이터셋을 구축하였다.

## 📌 Challenges & Solutions

### 1. 엔카 API 구조 분석

* 일반 HTML 크롤링이 아닌 API 기반 데이터 수집이 필요하였다.
* 개발자 도구(Network)를 활용하여 API 구조를 분석하고 해결하였다.

### 2. 보험이력 데이터 확보

* 기본 차량 정보만으로는 차량 상태를 충분히 반영하기 어려웠다.
* 추가 API 호출을 통해 보험이력 데이터를 수집하여 데이터셋에 결합하였다.

### 3. 모델 성능 개선

* 다양한 모델을 비교하였다.
* Optuna를 활용한 하이퍼파라미터 튜닝을 수행하여 성능을 향상시켰다.
