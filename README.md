# 🚗 Used Car Price Prediction

중고차 사이트 데이터를 직접 수집하고,
머신러닝 기반 가격 예측 모델 및 FastAPI 기반 예측 API를 구현한 프로젝트

---

# 📌 프로젝트 소개

## 프로젝트 개요

중고차 가격은 연식, 주행거리, 사고이력 등 다양한 요소에 의해 결정된다.
하지만 일반 사용자가 차량의 적정 시세를 판단하기 어렵다는 문제를 발견하였다.

이를 해결하기 위해 엔카(ENCAR) 사이트의 차량 데이터를 직접 수집하고,
머신러닝 기반 가격 예측 모델을 구축하였다.

또한 FastAPI를 활용하여 사용자가 차량 정보를 입력하면
예측 가격을 반환하는 API 형태의 서비스까지 구현하였다.

# ❗ Problem

중고차 가격은 다음과 같은 다양한 요소에 의해 결정된다.

* 차량 연식
* 주행거리
* 사고 이력
* 연료 타입
* 차량 트림

하지만 일반 사용자가 차량의 적정 시세를 판단하기 어렵고,
동일 모델 내에서도 차량 상태에 따라 가격 차이가 크게 발생한다.

또한 단순 차량 정보만으로는 실제 차량 상태를 충분히 반영하기 어렵다고 판단하였다.

따라서:

* 실제 중고차 데이터를 직접 수집하고
* 보험이력 데이터를 추가 결합하여
* 머신러닝 기반 가격 예측 모델을 구축하고자 하였다.

---

# 📌 Data Collection

## 데이터 출처

엔카(ENCAR) 사이트의 차량 데이터를 활용하였다.

아반떼 차량 데이터를 중심으로 데이터를 수집하였으며,
엔카 API 구조를 분석하여 차량 데이터를 확보하였다.

---

## 차량 기본 정보 수집

Python requests 라이브러리를 활용하여
엔카 API에 반복 요청을 수행하였다.

offset 기반 페이지네이션 방식을 적용하여
전체 차량 데이터를 자동 수집하였다.

---

## 수집 데이터

| 컬럼명  | 설명       |
| ---- | -------- |
| 제조사  | 차량 제조사   |
| 모델명  | 차량 모델명   |
| 배지   | 차량 트림 정보 |
| 연식   | 차량 연식    |
| 가격   | 차량 판매 가격 |
| 주행거리 | 누적 주행거리  |
| 연료   | 연료 타입    |
| 변속기  | 자동/수동    |
| 판매지역 | 차량 판매 지역 |

---

## 구현 내용

* offset 기반 반복 요청 자동화
* JSON 데이터 저장
* API 응답 예외 처리
* 중복 데이터 제거
* 서버 과부하 방지를 위한 sleep 적용

---

## 차량번호 추가 수집

기본 차량 정보만으로는 보험이력 데이터를 확인할 수 없었다.

이를 해결하기 위해 차량 ID를 활용한 추가 API 호출을 수행하여
vehicleNo(차량번호) 데이터를 추가 수집하였다.

---

## 보험이력 데이터 수집

차량번호와 차량 ID를 활용하여
보험이력 API 데이터를 추가 수집하였다.

이를 통해:

* 사고 이력
* 침수 여부
* 피해 금액
* 소유자 변경 이력

등 실제 차량 상태와 관련된 데이터를 확보하였다.

---

## 데이터 병합

최종적으로:

* 차량 기본 정보
* 차량번호 정보
* 보험이력 정보

를 병합하여 머신러닝 학습용 데이터셋을 구축하였다.

---

# 📌 Data Preprocessing

수집된 데이터에는:

* 중복 차량 데이터
* 결측 데이터
* 문자열 기반 숫자 데이터

등의 문제가 존재하였다.

이를 해결하기 위해 다음과 같은 전처리를 수행하였다.

---

## 수행한 전처리

* DUPLICATION 상태 데이터 제거
* 차량 ID 기준 중복 제거
* 문자열 데이터 숫자형 변환
* 보험금액 단위 통일
* 결측치 제거

---

## 데이터 수집 및 전처리 중 문제점

### 1. API 구조 분석 필요

엔카 사이트는 일반 HTML 크롤링보다
API 기반 데이터 구조 분석이 필요하였다.

개발자 도구(Network 탭)를 활용하여
실제 API 요청 구조를 분석하고 데이터를 수집하였다.

---

### 2. 중복 데이터 문제

동일 차량 데이터가 반복적으로 수집되는 문제가 발생하였다.

이를 해결하기 위해:

* 등록 상태 확인
* 차량 ID 기준 중복 제거

로직을 적용하였다.

---

### 3. 추가 정보 수집 문제

보험이력 데이터는 별도 API 호출이 필요하였다.

차량 ID와 차량번호를 조합하여
추가 요청을 수행하는 방식으로 해결하였다.
